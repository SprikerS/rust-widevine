#  🔓 DRM DECRYPTION KEYS

This project allows you to obtain decryption keys for content protected with **DRM** (Digital Rights Management) using rust

## 🚀 Features

- Automatic drm key acquisition
- Support for different types of licenses
- Implemented in **Rust** for high performance and security
- Easy to use and run with `cargo run`

## 🧱 Get started

1. Clone the repository

```bash
git clone https://github.com/SprikerS/rust-widevine.git
```

2. Run the project

```bash
cargo run
```

3. Enjoy the keys

> [!CAUTION]
> This tool will not work without your `.wvd` file as used by [pywidevine](https://github.com/devine-dl/pywidevine)
